# JSFX verification

Runs JSFX scripts generated by `ParametricPreset.jsfxScript` in [ysfx](https://github.com/JoepVanlier/ysfx)
(REAPER's EEL2 engine as a library) and compares the output sample by sample with SystemEQ's
`EQProcessor` and a 64-bit reference, at 44.1, 48 and 96 kHz.

```sh
# Build ysfx (needs CMake and Ninja).
git clone --depth 1 --recurse-submodules https://github.com/JoepVanlier/ysfx.git /tmp/ysfx
cmake -S /tmp/ysfx -B /tmp/ysfx/build -G Ninja -DCMAKE_BUILD_TYPE=Release -DYSFX_PLUGIN=OFF -DYSFX_GFX=OFF
cmake --build /tmp/ysfx/build

# Build the host and the checker, then compare some presets.
clang++ -std=c++17 -O2 -I /tmp/ysfx/include scripts/jsfx-verify/host.cpp /tmp/ysfx/build/libysfx.a \
  -framework CoreFoundation -framework Foundation -o /tmp/jsfx-host
swiftc -O Sources/EQCore/*.swift scripts/jsfx-verify/main.swift -o /tmp/jsfx-verify
mkdir -p /tmp/jsfx-scratch
/tmp/jsfx-verify /tmp/jsfx-host /tmp/jsfx-scratch path/to/preset.txt ...
```

Expected: differences around 1e-12 (−220 dB) from the 64-bit reference, and around 3e-8 (−150 dB) from
`EQProcessor`, which rounds its output to 32-bit floats.
